# 组件与署名

飞返竞技场复用 **meow-ai-arena** 的 C++ 比赛规则、地图与 13 份官方参赛程序。上游许可见发行包根目录的 `LICENSE.txt`（[项目主页](https://github.com/chen-006/meow-ai-arena)）。角色形象设计参考：**小叶子XIYZ（B 站）**；美术和制作：**喵了个猫了个咪了个猫**。模型与公司名称用于区分参赛选手，其余权利归各自权利人。游戏内使用原创中性豆包席位图标与上游 MIT 体素人偶，未采用上游单独标记为非 MIT 的豆包 PNG 头像。

本衍生版的游戏开发、联机服务和发行由 Codex 和 ChatGPT 完成；专服 Web 管理台前端由 Gemini 贡献。

Windows x64 便携包随附 OpenSSL 3.6.5、Zstandard 1.5.7、GCC 16.2/MinGW-w64 运行时。Ubuntu 24.04 x86_64 专服使用系统动态库 libssl3t64、libzstd1、libargon2-1 和官方 MsQuic 2.6.4 deb，13 个 Bot 用 GCC 13.3 静态构建。Linux 包另附安装版本清单、glibc 许可及 Bot 重链接材料。
