# 飞返竞技场 1.0.0

首个独立开源版本。可以带朋友上岛，也可以直接挑战原比赛中的 13 名 AI，无需 API Key。

- **玩游戏**：下载 `Flyback-Arena-1.0.0-Windows-x64.zip`。完整解压，双击 `Flyback.exe`。支持 2、3、4 席自由对战，12 张地图，可用键鼠或手柄操作。
- **开专服**：下载 `Flyback-Arena-1.0.0-Server.zip`，按系统选择 Windows x64 或 Ubuntu 24.04 x86-64。游戏连接使用 UDP；Web 管理台使用独立的 TCP 端口。临时局域网房不需要此包。
- **开局节奏**：等场地与人物显示后倒数 3 秒；真人局默认 0.8×，全 AI 对局仍是 1×，原始回放不额外插入倒数。
- **升级已有部署**：保留自己的 `server.toml`、运行数据及 `identity` 目录，避免客户端已保存的服务器指纹失效。

本衍生版的游戏开发、联机服务和发行由 **Codex 和 ChatGPT** 完成；专服 Web 管理台前端由 **Gemini** 贡献。

基于 [chen-006/meow-ai-arena](https://github.com/chen-006/meow-ai-arena) 的「回旋镖大作战」。项目源码采用 MIT，第三方资产和运行库沿用各自许可。
